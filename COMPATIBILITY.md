# DVD compatibility

DVD authoring varies heavily between titles, regions, and studios, so
compatibility is tracked from real-world reports rather than assumptions.

## How this is tracked

- Anyone can submit a **DVD compatibility report** using the GitHub issue form
  (New issue → *DVD compatibility report*).
- Confirmed results are summarised in the table below over time.
- Please do **not** upload copyrighted disc contents (ISO / VOB / decrypted
  DVD data) or CSS keys. A title, region, PAL/NTSC, and description are enough.

## Result legend

- **Works** — behaves as expected.
- **Partial** — works with issues (see notes).
- **Broken** — does not work.
- **Not tested** — not yet verified.
