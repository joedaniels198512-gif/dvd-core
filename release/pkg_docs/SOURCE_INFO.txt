MiSTer DVD Player 0.1.0-private-beta — SOURCE_INFO
==================================================

This ZIP redistributes third-party binaries. Corresponding source and
licence texts are in SOURCES/ and LICENSES/.

Our ARM/FPGA source remains in the project repository. A snapshot of the
ARM files used to build the player, launcher, rip helper, autostart
daemon source, and custom Main overlay is in:

    SOURCES/mister-dvd-player-arm/

No modifications were made to the upstream tarballs listed below.
FFmpeg is built from stock 6.0.1 with the configure flags in
player/build_mac.sh (also copied into the ARM snapshot).

Our tools (not upstream):
    dvd_launcher, dvd_rip_iso, dvd_av_threaded_test, dvd_autostart_daemon.sh
    MiSTer_DVD (Main_MiSTer overlay; dvd_main.cpp supervisor)
    Built with arm-unknown-linux-gnueabihf-gcc, -mcpu=cortex-a9,
    -mfpu=neon-vfpv3. See the ARM snapshot and build_*.sh scripts.

Custom Main is a snapshot of MiSTer-devel/Main_MiSTer at
    0a8fb44ccec6d69c8b7f158abd5fe8065ab2bf4f
plus isolated DVD launcher supervision. It is installed as
/media/fat/MiSTer_DVD and selected with [DVD-Player] main=MiSTer_DVD.
Stock /media/fat/MiSTer is not replaced. The autostart daemon source is
preserved but is not started by new installs.
