INSTALL
=======

[ ] Installer succeeds
[ ] /media/fat/MiSTer_DVD is present; stock /media/fat/MiSTer is unchanged
[ ] MiSTer.ini has [DVD-Player] main=MiSTer_DVD (and no duplicate daemon block)
[ ] /media/fat/games/DVD-Player exists
[ ] MiSTer DVD Player appears on the front page
[ ] Launcher starts automatically when the core is selected
[ ] Leaving the DVD core / reboot stops launcher and player
[ ] Re-entering DVD does not start a second launcher
[ ] Branding shows: MiSTer DVD Player / by Mojojojo198512
[ ] Footer shows: Beta 0.1.0
[ ] Instruction shows: To exit DVD, hold BACK for 3 seconds

BUG REPORT
==========

If something fails:

1. Stop after reproducing the issue once if possible.
2. Scripts -> Export MiSTer DVD Player Logs
3. Send:

       exported log archive
       DVD title
       exact menu / action immediately before failure
       CRT or HDMI
       physical disc vs ISO
       this checklist (what passed / failed)
